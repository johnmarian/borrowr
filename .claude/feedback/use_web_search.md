# Use web search proactively

Use web search proactively whenever there is uncertainty about a framework API, tool behaviour, or external fact.

**Why:** Claiming `#[before]` existed in cucumber-rs without verifying it wasted time and eroded trust. The user should not have to ask for a web search.

**How to apply:** Any time you are about to state something as fact about an external library, tool, or API that you are not certain of, search first.
