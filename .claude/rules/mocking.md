# Mocking 3rd Party APIs

## Principle

We do not test 3rd party code — we trust it works. What we test is that **we call it
correctly**: right method, right arguments, right number of times.

## Pattern

1. Define a private trait that mirrors the part of the 3rd party API we actually use
2. Write a thin concrete struct that delegates to the real 3rd party call
3. The testable function takes `&dyn Trait` (injected)
4. A public wrapper hardwires the real implementation for production
5. Tests inject a `MockX` generated by mockall

```rust
use inquire::Select;
#[cfg(test)]
use mockall::automock;

// 1. Trait mirrors the 3rd party API surface we use
#[cfg_attr(test, automock)]
trait Selector {
    fn select(&self, prompt: &str, options: Vec<String>) -> Option<String>;
}

// 2. Thin concrete struct — just delegates to the real call
struct InquireSelector;

impl Selector for InquireSelector {
    fn select(&self, prompt: &str, options: Vec<String>) -> Option<String> {
        Select::new(prompt, options).prompt().ok().map(|s| s.to_string())
    }
}

// 3. Private testable function takes injected trait
fn run_with(selector: &dyn Selector) { ... }

// 4. Public entry point hardwires the real implementation
pub fn run() {
    run_with(&InquireSelector);
}
```

## Tests verify the call, not the result

Use `.with()` to assert the exact arguments passed and `.times()` to assert call count.
This catches wrong prompt text, wrong items, wrong order, or the call being skipped entirely.

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use mockall::predicate;

    #[test]
    fn run_calls_select_with_correct_prompt_and_items() {
        let mut mock = MockSelector::new();
        mock.expect_select()
            .with(
                predicate::eq("What would you like to do?"),
                predicate::eq(vec![
                    "Lend something out".to_string(),
                    "View active loans".to_string(),
                    "Borrow something".to_string(),
                    "Quit".to_string(),
                ]),
            )
            .times(1)
            .returning(|_, _| Some("Quit".to_string()));

        run_with(&mock);
    }
}
```

## Visibility

The trait, mock, and concrete struct are all **private to the module**. Only the
public `run()` function is exposed. `MockSelector` only exists in test builds
(`#[cfg_attr(test, automock)]`) and never leaks into production code.
